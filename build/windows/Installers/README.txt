Place the Tesseract Windows installer here before running build_windows.bat.

File name required: tesseract-ocr-w64-setup.exe

Download from:
  https://github.com/UB-Mannheim/tesseract/wiki

Choose the latest 64-bit release (e.g. tesseract-ocr-w64-setup-5.x.x.xxx.exe)
and rename it to: tesseract-ocr-w64-setup.exe
